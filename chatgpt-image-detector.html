How to check if an image was made with ChatGPT

  1. Get the original file. Ask the sender for the file itself, or download it directly from where it was first posted. Avoid screenshots.
  2. Drop it into the checker above. The analysis runs in your browser in about a second.
  3. Read the verdict and the evidence. If OpenAI's label is present you will see “AI-generated” with ChatGPT or OpenAI named as the source.
  4. Confirm the signature (optional). Use the “Verify credentials officially” link on the result to check the digital signature with the Content Credentials verifier.

Why ChatGPT images can be detected

OpenAI attaches Content Credentials – a label based on the open C2PA standard – to images created with ChatGPT and its image API. The label is stored inside the file and states that the image was produced by an AI model, which tool produced it and when. Because the label is cryptographically signed, it is difficult to forge.

OpenAI has also said it adds an invisible watermark to its images. RealTell does not read invisible watermarks; it reads the Content Credentials label, which is the part stored openly in the file.

When the checker can't tell

The label lives in the file's metadata, and metadata is easy to lose. You will usually see “No AI labels found” when:

  • someone took a screenshot of the image instead of saving it;
  • the image was sent through WhatsApp, Instagram, Facebook, X or other apps that strip metadata;
  • it was edited and exported in a program that doesn't preserve Content Credentials;
  • it was cropped or converted with an online tool.

In those cases the absence of a label tells you nothing. Look for visual signs of AI generation and run a reverse image search to find the earliest copy.

Spotting ChatGPT images by eye

ChatGPT's image generation is very good, so visual checks are hints, not proof. Things worth a second look include text that is almost-but-not-quite correct on signs and packaging, overly clean and evenly lit scenes, repeated patterns in backgrounds, and small objects that merge into each other. Default output sizes such as 1024 × 1024, 1024 × 1536 and 1536 × 1024 are also common.

Frequently asked questions

Can RealTell detect every ChatGPT image?

Only images that still contain OpenAI's Content Credentials. If the label was removed – for example by a screenshot or a social media upload – no metadata-based tool can see it.

Does this work for DALL-E 3 images?

Yes. DALL-E images created through ChatGPT or the OpenAI API carry the same kind of Content Credentials label.

Is my image uploaded to check it?

No. RealTell analyses the file inside your browser. It never leaves your device.
