Stable Diffusion Image Checker & Prompt Reader

Many Stable Diffusion tools save the prompt, model and settings inside the image file. Drop a PNG or JPG below to find out if it was generated with Stable Diffusion – and see the data it contains.

What RealTell can read

Popular Stable Diffusion interfaces write generation details into the images they save. RealTell recognises:

  • Automatic1111, Forge and Fooocus – the prompt, negative prompt, sampler, steps, CFG scale, seed and model.
  • ComfyUI – the full node workflow used to create the image.
  • InvokeAI and NovelAI – their own generation metadata formats.

Open “Show file details” on the result to see the stored text. This is also a handy way to recover a prompt from one of your own images.

Why some Stable Diffusion images show nothing

The settings are usually stored in PNG text fields. Converting the image to JPG or WebP, uploading it to most websites, or saving it from a chat app removes them. Some apps also offer an option to save images without metadata.

Privacy tip for creators

If you share your own AI images, remember that the embedded prompt and settings travel with the file. If you'd rather keep your prompt private, export a copy without metadata before posting – and if you want people to know the image is AI-made, say so in the caption.

Frequently asked questions

Can I see the prompt of any AI image?

Only if the tool saved it and it hasn't been removed. ChatGPT, Midjourney and most online generators don't embed the full prompt.

Does it work with SDXL and FLUX images?

Yes, as long as the interface you used saved its metadata in one of the supported formats.

Are my images uploaded?

No. Everything is processed locally in your browser.
